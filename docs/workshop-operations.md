# 워크샵 운영

## 규모

| 항목 | 값 |
| --- | --- |
| GL5 | 6대. 조별 1대씩 5대 + 기준국 1대 |
| 조 | 5개 |
| 리눅스 머신 | Jetson 1대 |
| 네트워크 | 공유기 1대 |

## 스테이션 배치

**기준국 (조건 없이 항상 운영).** Jetson + 6번째 GL5. 워크샵 내내 스트리밍 상태로
둔다. 공유기 LAN에 Zenoh 라우터와 noVNC를 열어두면 어떤 OS의 누구든 브라우저만
열면 살아있는 3D 데이터를 본다.

이건 선택지가 아니라 안전망이다. 조별 호스트가 몇 개 실패하든 워크샵이 빈손으로
끝나지 않게 한다. 실습 초반에 "일단 이게 라이다 데이터다"를 보여주는 용도로도 쓴다.

**조별 스테이션 5개.** 각 조가 GL5 1대와 라이다 호스트 1대를 갖는다. 센서는 호스트에
랜 케이블로 직결한다. 스위치가 없어도 되고, 링크가 서로 분리돼 있으므로 **모든
센서가 기본 주소 그대로여도 충돌하지 않는다.**

조원들은 자기 노트북으로 조의 호스트 화면을 본다.

## 라이다 호스트를 무엇으로 세우나

리눅스 머신이 Jetson 1대뿐이라 나머지 5자리를 채워야 한다. 위에서부터 확인해서
되는 것을 쓴다.

1. **학교 컴퓨터실.** 동일한 머신이라 한 대에서 검증한 절차가 전부에서 재현된다.
   가장 신뢰도가 높다. [department-checklist.md](department-checklist.md) 로 먼저
   문의한다.
2. **Mac + UTM 브리지.** 참가자에 맥이 많아 통하면 범용성이 크지만 macOS 26에
   미해결 버그가 있다. [preflight-macos.md](preflight-macos.md) →
   [host-macos-utm.md](host-macos-utm.md) 순으로 진행한다.
3. **Ubuntu Live USB.** x86 머신을 USB로 부팅한다. 네트워크 문제가 통째로 사라지지만
   Apple Silicon은 부팅할 수 없다. [host-live-usb.md](host-live-usb.md)
4. **Windows 11 WSL2 mirrored.** [networking-windows.md](networking-windows.md)

## 조원이 화면을 보는 두 가지 방법

**기본: 호스트의 noVNC를 연다.** 브라우저로 `http://<호스트IP>:6080/vnc.html?autoconnect=1`
을 열면 호스트의 RViz를 그대로 본다. 와이파이에 VNC 스트림 하나만 흐르므로 대역폭
부담이 거의 없다. 공유기만 있는 환경에서는 이쪽이 기본이다.

**심화: 각자 컨테이너에서 RViz를 띄운다.** Zenoh 클라이언트로 조의 라우터에 붙어
포인트클라우드를 직접 구독한다. ROS2 경험은 이쪽이 진하지만 조원 수만큼 클라우드가
복제된다.

```bash
cp .env.example .env      # ROUTER_HOST 를 조의 호스트 주소로
docker compose --profile viewer up -d
docker compose exec viewer rviz2
```

조당 Zenoh 뷰어를 몇 명까지 허용할지는 대역폭 실측 후 정한다. 라이다 호스트에서
`ros2 topic bw /lidar0/pointcloud` 로 잰다. 10 MB/s를 넘으면 무선으로 여러 명에게
밀지 말고 noVNC로 통일한다.

## 당일 진행 순서

1. **이미지 확인.** 전날 미리 받아오게 공지한다. 현장에서 받으면 1GB씩 × 인원이라
   와이파이가 죽는다. 못 받아온 사람을 위해 USB에 `docker save` tar를 담아 간다.
2. **기준국 켜기.** 가장 먼저 띄운다. 전원에게 주소를 공지하고 브라우저로 열게 한다.
   이 시점에 모두가 라이브 라이다 데이터를 본다.
3. **실습 본편.** 각자 `:dev` 이미지로 SDK를 빌드한다. **라이다가 필요 없다.**
   막히면 `:prebuilt` 로 전환한다.
4. **조별 연결.** 조의 호스트에 GL5를 직결하고 `soslab_ethinfo` 로 플래시된 포트를
   읽은 뒤 노드를 띄운다.
5. **조원 시청.** 호스트의 noVNC 주소를 공유한다.

3번이 라이다 없이 진행된다는 점이 중요하다. **실습의 핵심은 라이다가 아니라 설치와
빌드이므로, 하드웨어가 전부 실패해도 워크샵의 본편은 유지된다.**

## 후퇴선

| 상황 | 대응 |
| --- | --- |
| 조별 호스트가 전부 성공 | 계획대로 조마다 자기 센서를 본다 |
| 일부만 성공 | 성공한 조는 자기 센서로, 나머지는 순번을 돌아가며 연결하고 평소에는 기준국을 본다 |
| 전부 실패 | 기준국 하나로 전원이 라이브 데이터를 본다. 빌드 실습은 그대로 진행된다 |

## 챙겨갈 것

- 랜 케이블 6개 이상
- 공유기와 전원
- USB 이더넷 어댑터 (컴퓨터실에 랜 포트가 없거나 맥을 쓸 경우 조당 1개)
- 이미지 tar를 담은 USB
- 기준국용 Jetson과 전원, 모니터 또는 SSH 접속 수단
- GL5 전원 어댑터 6개

## 사전 실측 (반드시 행사장에서)

공유기를 행사장에 설치한 뒤 뷰어가 라우터에 붙는지 확인한다. 와이파이의 AP 클라이언트
격리가 걸리면 같은 망에 있어도 단말끼리 통신이 막힌다.

```bash
# 라이다 호스트
ss -ltnp | grep 7447
# 뷰어
nc -vz <호스트IP> 7447
```
