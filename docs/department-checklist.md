# 학과 문의 체크리스트

컴퓨터실을 쓸 수 있는지가 준비의 1순위다. 동일한 머신이 여러 대 있으면 **한 대에서
검증한 절차가 모든 조에서 그대로 재현되기** 때문이다. 개인 노트북 5종을 각각 뚫는
것과는 신뢰도가 비교되지 않는다.

아래를 그대로 복사해서 문의하면 된다.

---

## 문의 내용

안녕하세요. SOSLAB 라이다 워크샵 실습실 사용 관련해 문의드립니다.

ROS2 기반 라이다 실습을 진행하려고 하며, 라이다 센서를 컴퓨터에 이더넷으로 직접
연결해 데이터를 수신하는 과정이 포함됩니다. 아래 항목을 확인해주시면 감사하겠습니다.

**일정과 규모**

1. (날짜/시간)에 실습실을 사용할 수 있을까요? 사용 가능한 좌석은 몇 개인가요?

**소프트웨어 환경**

2. 설치된 운영체제와 버전은 무엇인가요? Windows라면 11 22H2(빌드 22621) 이상인가요?
3. 실습을 위해 관리자 권한을 받을 수 있을까요? 가능하다면 WSL2와 Docker를 설치해도
   되는지 궁금합니다.
4. 관리자 권한이 어렵다면 USB 부팅이 허용되는지 궁금합니다. BIOS 부팅 메뉴에
   접근할 수 있나요? Secure Boot는 켜져 있나요?
5. 재부팅하면 설정이 초기화되는 복원 솔루션(Deep Freeze 등)이 적용돼 있나요?

**네트워크**

6. 각 컴퓨터에 **유선 랜 포트가 있고 비어 있는지** 궁금합니다. 교내망 케이블이
   연결돼 있다면 실습 중 잠시 분리하고 라이다를 연결해도 될까요?
7. 실습실에서 외부 인터넷으로 약 1GB 정도의 도커 이미지를 내려받을 수 있나요?
   방화벽이나 프록시 제한이 있나요?

## 답변에 따른 분기

| 답변 | 우리가 할 일 |
| --- | --- |
| 3번이 가능 | WSL2 mirrored + docker-ce를 설치한다. 재부팅이 없고 절차를 복사할 수 있다 |
| 3번은 불가, 4번이 가능 | Ubuntu Live USB로 부팅한다. 설치 흔적이 남지 않는다 |
| 3번과 4번 모두 불가 | 컴퓨터실은 뷰어 전용이 된다. 라이다 호스트는 개인 장비로 따로 세운다 |
| 6번이 부정 | USB 기가비트 이더넷 어댑터가 조당 1개씩, 총 5개 필요하다 |
| 7번이 부정 | 이미지를 USB에 담아 가서 `docker load` 로 넣는다 |

2번에서 Windows 10이 나오면 WSL2 경로는 불가능하다. mirrored 네트워킹 모드가 없고
대안도 없다. 그 경우 4번이 유일한 길이다.

5번에서 복원 솔루션이 걸려 있으면 오히려 좋다. 무엇을 설치하든 원복되므로 허가를
받기 쉽다. 다만 실습 중간에 재부팅되지 않도록 확인해야 한다.
